# Implementation plans

`active/` holds plans that are planned, in progress, blocked, or otherwise unresolved.
`completed/` holds plans whose required closure checks passed. Move the same file between these
directories; do not keep a duplicate. Use lowercase hyphenated task names.

Plans record temporary execution steps. Durable decisions belong in the project's instruction or
architecture files. Plans and briefs are ignored locally and remain in this checkout across moves;
they are not delivered to other clones.

`briefs/` holds Portuguese working documents for points awaiting the user; they grant no execution
authority.
